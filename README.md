# 抖音评论私信工具

本地单页工具，可按视频链接拉取评论、按博主主页批量拉取多个作品的评论，并从评论列表中选择**单个**用户发送私信。页面、Cookie 和抓取结果都只在本机处理，不经过任何第三方服务。

> 适用场景：抖音运营、用户调研、竞品分析、评论区洞察。

---

## 功能一览

- **加载单个视频评论**：粘贴一条视频链接，设置数量（最多 200 条），点一下即可拉取一级评论，包含头像、昵称、评论内容、点赞数、IP 属地等。
- **批量拉取博主评论**：粘贴博主主页链接，设置作品数（最多 10 个）和评论总数（最多 1000 条）。工具先抓作品列表，再逐个作品扒评论，几秒内拿到一批数据。
- **发送私信**：评论列表里选中任意用户，右侧显示 UID、签名、完整评论；写好内容点发送即可。**每次只发给一个用户，不支持批量群发**，避免触发平台风控。
- **全本地运行**：Cookie、数据只存在本地；接口所需的 `a_bogus`、`msToken` 等签名参数全部在本机用 Node.js 计算生成。

更详细的能力边界、限制和故障排查见 [功能说明](docs/usage.md)。

## 环境要求

- Python 3.10+
- Node.js 18+
- 同级目录中已克隆 `DouYin_Spider` 项目（签名与协议依赖），或在 `.env` 中配置 `DOUYIN_SPIDER_ROOT` 指向其路径

## 安装

```bash
# Python 依赖（推荐使用 uv）
uv venv
uv pip install -r requirements.txt

# Node.js 依赖（用于本地签名计算）
npm install
```

> 不使用 uv 时，也可用 `python -m venv .venv` + `pip install -r requirements.txt`。

## 启动

```bash
uv run python app.py
```

或：

```bash
python app.py
```

服务会自动在 `127.0.0.1` 上选择可用端口并打开浏览器。按 `Ctrl+C` 停止。

> 出于 Cookie 安全考虑，服务**只允许监听 `127.0.0.1` / `localhost`**，不会暴露到局域网。

## 配置

Cookie 可在页面右侧保存，也可写入项目根目录 `.env`（已加入 `.gitignore`，不会被提交）。若本工具未配置 Cookie，会自动读取同级 `DouYin_Spider/.env` 中的 `DY_COOKIES`。

私信功能还需要两项浏览器本地凭证（`localStorage` 值），获取步骤见 [配置说明](docs/configuration.md)。

`.env` 示例可参考 `.env.example`：

```dotenv
DY_COOKIES=
DY_WEB_PROTECT=
DY_SECURITY_KEYS=
DOUYIN_SPIDER_ROOT=
APP_HOST=127.0.0.1
APP_PORT=8765
```

## 使用流程

1. 粘贴视频链接，设置最多评论数，点击「加载评论」。
2. 或粘贴博主主页链接，设置作品数和评论总数，点击「拉博主评论」。默认最多 10 个作品、100 条评论。
3. 单击一条评论，在右侧确认目标用户并填写私信内容。
4. 点击「发送私信」。每次请求只允许一个接收者。

长时间拉取可点击结果栏中的「停止拉取」随时中断。

## 技术特点

- **零框架依赖**：使用 Python 标准库 `http.server` 启动本地服务，不引入 Flask / Django 等重型框架。
- **签名自研**：抖音接口的 `a_bogus`、`msToken` 等参数全部在本地计算，不依赖任何外部签名服务。
- **评论到私信一条链路打通**：找到目标用户、查看评论、发送私信，全部在一个页面内完成。

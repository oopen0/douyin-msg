# 功能说明

## 拉取单个视频评论

支持完整视频链接、带 `modal_id` 的分享链接和 `v.douyin.com` 短链接。单次最多返回 200 条一级评论；达到设定数量或接口无更多数据时停止。

## 拉取博主评论

支持博主主页链接和短链接。工具先按发布时间读取指定数量的作品，再逐个作品抓取一级评论。默认最多检查 10 个作品、合计返回 100 条评论；作品数最多 10 个，评论总数可在页面设置为 1–1000 条。达到评论总数后立即停止后续作品，结果会标注来源作品。

该操作请求量较多，耗时取决于作品数、评论数和抖音接口响应。页面在请求结束前会保持加载状态，请勿重复点击。

拉取过程中可点击结果栏右侧的“停止拉取”。页面会立即退出加载状态，后端会在当前抖音请求结束后停止后续分页和作品。

## 发送私信

必须先从评论列表选择一个用户。后端只接受一个数值 UID 和一段文本，不提供批量接收者参数。发送结果以抖音 IM 接口响应为准；缺少安全凭证、目标用户限制陌生人消息或触发平台风控时会显示失败原因。

请遵守平台规则和适用法律，避免高频或未经同意的营销消息。

## 常见问题

- “Cookie 缺少 sessionid”：重新登录网页版并复制完整 Cookie。
- “私信凭证未配置”：按 [配置说明](configuration.md) 获取两项 `localStorage` 值。
- “加载本地抖音核心模块失败”：重新执行 `uv pip install -r requirements.txt` 和 `npm install`。
- 接口返回验证或风控提示：先在浏览器正常访问抖音并完成验证，再更新 Cookie。
